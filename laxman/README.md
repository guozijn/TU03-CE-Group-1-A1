# Laxman's Individual Analysis Files

This folder contains the code, sample data, and Tableau workbook used to 
support the individual data exploration and analysis for Assignment 1 
(Analytic Plan), based on the LinkedIn Jobs and Skills 2024 dataset 
(Kaggle: asaniczka/1-3m-linkedin-jobs-and-skills-2024).

## Contents

### Python Scripts
- **`sample.py`** — Creates smaller sample files  from 
  the full linkedin_job_postings.csv and job_summary.csv datasets.
- **`stats.py`** — Computes full-dataset statistics across all three source 
  files, including missing value counts, distinct value counts, and 
  category breakdowns (job level, job type, search country).

### Sample Data
- **`sample_postings.csv`** —  sample of the LinkedIn job postings dataset.
- **`sample_summary.csv`** —  sample of the job description summaries dataset.

### Tableau Workbook
- **`Skill analysis.twb`** — Tableau workbook containing the exploratory 
  visualisations used in the individual analysis, including skills 
  co-occurrence, seniority level, work arrangement, and geographic 
  distribution of Business Analyst-related job postings.
